# Make the Judge Laugh in One Line

A smartwatch celebrates 10,000 steps — then the twist: those steps were not exercise at all, just pacing around the kitchen while dodging a phone call. Setup, surprise, punchline at the end. One sentence, 139 characters.

> My smartwatch congratulated me on 10,000 steps today, which is generous, because I was only pacing around the kitchen dodging a phone call.

`main.py` writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
